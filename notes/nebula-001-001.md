# Nebula 001-001 Notes

## Interpretation

Create a Godot-friendly nebula using three pre-rendered 2048×2048 transparent RGBA layers rather than a runtime procedural shader. Use green, purple, magenta, and restrained red; favor diffuse clouds with occasional soft filaments; omit stars; preserve a black background; and compose the result at 3840×2160 with a 1200×675 preview. Store the procedural construction in Python and the compositing planes in the generated Blend file. Record inexpensive opposing rotation speeds for later Godot animation.

## Observations

The experiment successfully creates all parts of the intended production pipeline: three independently baked RGBA cloud images, an opaque black background, a 4K static composite, a 1200×675 preview, and three compositing planes carrying suggested Godot rotation speeds. This satisfies the technical goals of pre-rendering the expensive procedural work and leaving only simple texture transforms and modulation for runtime animation.

The artistic result does not yet fulfill the nebula goal. The three layers have too much alpha coverage, so their overlap nearly fills the frame and largely eliminates the black background. The composite reads as a broad, softly mottled magenta field rather than a distribution of distinct green and purple clouds. Green influence is visible but too muted after compositing, the center is not quiet enough for the logo, and the filament layer does not yet create recognizable broad ephemeral filaments. Overall exposure is also brighter and more uniform than intended.

No stars are present, as required. The texture softness is appropriate in principle, and the absence of sharp procedural edges supports the desired early-CGI direction. The next experiment should retain the three-layer architecture while increasing the transparent portion of each color ramp, lowering peak alpha, strengthening spatial separation between green and purple regions, and creating larger-scale gaps of true black.

The three 2048-square layers are approximately 7 MB each as PNG files, while the 4K composite is approximately 17 MB before Godot import compression. Runtime GPU memory and overdraw should be evaluated later using Godot's VRAM-compressed imports; the current files are suitable source artifacts for that test.

## Comparison with previous preview

There is no previous nebula preview. This experiment establishes the nebula's independent version and experiment series, its procedural source, production texture naming, compositing scene, static fallback, and prospective low-cost Godot animation method.
