# Notes for logo 006-004

## Interpretation

- Repeat the radius-one construction from 006-003 while translating the completed circular arrangement so its world-space bounds are centered at the inherited camera target.

## Observations

The preview remained an off-center horizontal projection rather than revealing the circular arrangement. Inspection of the transform sequence indicates that Blender's dependency graph had not been updated after assigning the individual arc locations and tangent rotations. The shared X/Y baking step therefore read stale object matrices from the prior horizontal layout, and the centering calculation was ineffective for the same reason.

No useful artistic conclusion about the radius-one circle should be drawn from this preview. The run is retained as a diagnostic experiment. Geometry remains approximately 13,284 triangles.

## Comparison with 006-003

The intended centering change is not visibly realized because both experiments bake stale pre-arc transforms. A follow-up must update the view layer after arc placement, center the evaluated arrangement, update it again, and only then apply the shared X/Y orientation.
